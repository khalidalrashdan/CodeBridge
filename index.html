Lesson 1: Variables

A variable is used to store information.

Example:



int age = 15;

Here, age stores the number 15.

Quiz

Lesson 2: Data Types

Java has different data types.

  • String stores text.
  • int stores whole numbers.
  • double stores decimal numbers.
  • boolean stores true or false.

Quiz

Which data type stores true or false?

  1. String
  2. int
  3. boolean


Lesson 3: If Statements

An if statement allows a program to make decisions.

Example:



if (age >= 18) {
System.out.println("Adult");
}

Quiz

Which keyword is used to make a decision?

  1. if
  2. loop
  3. print


Lesson 4: Loops

A loop repeats code multiple times.

Example:



for (int i = 0; i < 5; i++) {
System.out.println(i);
}

Quiz

Which keyword is commonly used to create a loop?

  1. for
  2. String
  3. class
